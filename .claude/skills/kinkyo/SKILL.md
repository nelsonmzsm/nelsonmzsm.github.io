# 近況記事の下書き作成

クライアント（水嶋さん）から素材を受け取り、近況記事の下書きを作成する。

## 受け取る素材（どれか1つ以上）

- 話した内容のテキスト（音声入力の文字起こし、メモ、箇条書き、なんでも）
- 関連リンク（告知ページ、記事、SNS投稿など）
- 音声ファイルのパス → **現状ローカルに文字起こし環境がないため**、以下を案内する：
  「スマホの音声入力やWindowsの音声入力（Win+H）で文字にして貼り付けてもらえれば、そこから下書きします」

## 手順

1. 素材から記事を構成する。トーンは他の近況記事に合わせる：一人称「〜しています」調、短め（2〜6文）、宣伝臭を消して等身大に
2. URLが渡された場合は WebFetch で内容を確認し、記事内に `[リンクテキスト](URL)` で自然に埋め込む
3. `src/content/news/<YYYY-MM-スラッグ>.md` を作成する：
   - frontmatter: `title`（30字以内・体言止めか「〜ました」）、`date`（今日、または素材で指定された日）、`summary`（60字以内）、**`draft: true`**
   - スラッグは英語小文字ケバブケース
4. 下書き全文をユーザーに見せて、修正点を聞く
5. OKが出たら `draft: true` を削除して公開状態にする（ビルド確認まで行う）

## 注意

- 事実の創作はしない。素材にない日付・数字・固有名詞を補わない。不明点は聞く
- 「健」の読みは「けん」ではない。ふりがなが必要なら「ねるそん みずしま」
